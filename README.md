# RICO ANIMATOR 🎬

Make professional stick figure animations in minutes — no coding, no drawing skills needed.

---

## ⚡ One-Time Setup (do this once)

Open Command Prompt and run:

```
pip install pygame opencv-python numpy Pillow
```

---

## 🚀 How to Launch

1. Download or clone this repo to your computer
2. Open the folder
3. **Double-click `run.bat`**

The app opens instantly.

---

## 🎮 How to Use

1. **Click action buttons** on the right (Run, Jump, Punch, Kick, etc.)
2. Your moves appear in the **timeline** at the bottom
3. Click **▶ PLAY PREVIEW** to watch the animation
4. Adjust **Background**, **Figure Color**, and **Speed** as you like
5. Click **💾 EXPORT MP4** to save the video to your computer

---

## 🎬 Available Moves

| Button | What happens |
|--------|-------------|
| 🧍 IDLE | Character stands still |
| 🏃 RUN | Full running cycle |
| 🦘 JUMP | Crouch → leap → land |
| ⬇️ LAND | Absorb landing |
| 👊 PUNCH | Fast punch with impact flash |
| 🦵 KICK | Snap kick |
| ↩️ DODGE | Side dodge |
| 🌀 SPIN | Spin kick |
| 💀 DEATH | Dramatic fall |

---

## 💡 Tips

- Chain moves together: e.g. **Run → Jump → Punch → Death** for a cool fight scene
- Use **Black background + White figure** for a classic Rico look
- Increase **Speed** slider for faster, more intense action
- Click ✕ on any move in the timeline to remove it
- Export as many videos as you want — it's 100% free
